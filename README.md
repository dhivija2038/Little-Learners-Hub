# Little Learners Hub 🌟

**Little Learners Hub** is a responsive educational web application designed to create an engaging and value-based learning environment for children. The platform aims not only to support early childhood education but also to help children develop social ethics, moral values, gender equality awareness, and personality development skills.

The project provides an interactive and visually appealing interface where children can explore educational content through videos and value-based learning sections.

### Features

* Responsive and user-friendly design
* Interactive navigation bar and smooth scrolling
* Image carousel for engaging content display
* About section explaining educational goals
* Core values section covering:

  * Respect
  * Kindness
  * Equality
  * Empathy
  * Discipline
  * Confidence
* Educational video learning section
* Social media footer integration

### Technologies Used

* HTML5
* CSS3
* Bootstrap 4
* JavaScript
* jQuery
* Font Awesome

### Objective

The main objective of Little Learners Hub is to create a digital learning space that helps children gain knowledge while building strong moral values and developing positive character traits from an early age.
